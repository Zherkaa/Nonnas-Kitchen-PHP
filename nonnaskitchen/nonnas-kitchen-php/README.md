# Nonna's Kitchen - PHP Assignment

A simple Albanian restaurant website for the Lesson 5 assignment on reusing code with PHP `include`.

## Files
- `header.php` - shared page header and navigation
- `footer.php` - shared footer and current copyright year
- `index.php` - homepage; includes header and footer
- `menu.php` - menu page; includes header and footer
- `style.css` - basic page styling

## How to run
1. Install XAMPP and start Apache.
2. Place the `nonnas-kitchen-php` folder in `C:\xampp\htdocs\`.
3. Open `http://localhost/nonnas-kitchen-php/` in your browser.
4. Use the Home and Menu links to navigate between pages.

PHP must run through a PHP-enabled server; GitHub Pages alone cannot run PHP.
